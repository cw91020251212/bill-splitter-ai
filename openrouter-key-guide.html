用 Google 帳戶登入Sign in with Google

按 Google「G」登入。

Choose Google to sign in.

按 New keyTap New key

按 New key。

Tap New key.

選到期日Choose an expiry

選一個到期日（圖中示範 1 year）。

Choose an expiry (1 year is shown).

設定額度Set a limit

要自訂額度，就選 Custom amount。

Choose Custom amount to set your limit.

建立金鑰Create the key

按 Create 建立金鑰。

Tap Create to make the key.

複製金鑰Copy the key

按 Copy 複製金鑰。

Tap Copy to copy the key.

貼入 AppPaste it into the app

貼入 API 金鑰欄，按「儲存並驗證」。

Paste into the API key field, then tap Save & Verify.
